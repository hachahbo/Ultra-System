What changed

Seven fixes to the Users table.

  1. 1
    One toolbar rowSearch, filters, scope and actions on a single line. "Without Trashed" became a proper Active/Trashed/All segmented control — it's a state, not a button. Active filters show as removable chips.
  2. 2
    Filter row rebuilt, not removedStill inline under the headers, but subordinate to them — 38px, no uppercase, controls on a lighter surface so they read as inputs rather than a second row of column titles. One control per column instead of an input plus a funnel icon. A column carrying a value turns accent, so active filters are visible without a legend. The stray val placeholder and the mystery refresh icon are gone; the row end is a clear-all that disables itself when there is nothing to clear. Collapsible from the toolbar, and chips appear only when it's collapsed.
  3. 3
    13 columns → 10Photo + Username + First Name + Last Name collapsed into one User cell: avatar, full name, username beneath. No more truncated "First Na…" headers. And the photo has an initials fallback — the old table rendered broken-image glyphs.
  4. 4
    Status is green, not amberAmber reads as a warning. Active is a success state, so it uses success green and stops competing with the orange accent.
  5. 5
    Booleans became glyphsEvery "No" was a red pill, so a perfectly healthy table looked like a wall of errors. True is a green check, false a dimmed dash — the eye scans for the exceptions instead of drowning in them.
  6. 6
    Two pagers, one componentTop and bottom, so you can page without scrolling back up — but rendered by a single function, which is what the old markup got wrong. Duplicated markup drifts; two mounts of one renderer can't. Both slimmed, both inside the card, and Go to added — it doubles as the current-page readout and earns its keep the moment the page count passes ~8. Try the 1,240 rows toggle to see the ellipsis window.
  7. 7
    Selection does somethingThe checkboxes had no visible consequence. Selecting rows now swaps the toolbar for a bulk action bar. Tick a row to see it.

Row height dropped 57px → 44px, with a compact 34px mode. At 50 rows per page that's roughly 650px less scrolling.
